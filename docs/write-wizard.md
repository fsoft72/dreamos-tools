# HOW TO WRITE A WIZARD

## Introduction

This document describes the guidelines about how to create a DreamOS Wizard Application.

## Features

**ALWAYS FOLLOW THESE POINTS**:
	- Every wizard is GTK4
	- Every wizard starts with a Welcome page with the ./assets/ball.png logo and title
	  (eg.  (logo) File System Extender
	- Wizard navigation buttons are always AT THE BOTTOM of the page
