# Opera

Opera web browser with built-in privacy and productivity features (stable channel).

![Opera](screenshot.png)

## Notes

- Installed with `apt` from the official Opera repository, which is added if missing, so updates arrive with the normal system updates.
- Uninstall removes the package and leaves the repository in place.
- Re-run **Install** at any time to update immediately.

More information on [the project site](https://www.opera.com/).
