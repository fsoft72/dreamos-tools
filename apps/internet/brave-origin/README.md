# Brave Origin

A minimal Brave: best-in-class privacy with just the features you want.

![Brave Origin](screenshot.png)

## Notes

- Installed with `apt` from the official Brave repository, which is added if missing, so updates arrive with the normal system updates.
- Free on Linux.
- Uninstall removes the package and leaves the repository in place (it is shared with the other Brave channels).
- Re-run **Install** at any time to update immediately.

More information on [the project site](https://brave.com/origin/).
