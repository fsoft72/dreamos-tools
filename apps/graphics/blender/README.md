# Blender

Free and open source 3D creation suite: modeling, sculpting, animation, rendering, compositing, video editing and more.

![Blender splash screen](screenshot.png)

## Notes

- Always installs the **latest** stable release from `download.blender.org` (official Linux x64 build), checksum verified.
- Installed for **your user only**, no system files are touched: Blender in `~/.local/opt/blender`, the `blender` command in `~/.local/bin` and a menu entry in `~/.local/share/applications`.
- Make sure `~/.local/bin` is in your `PATH` to use the `blender` command.
- Re-run **Install** at any time to update to the newest release.

More information on [the project site](https://www.blender.org/).
