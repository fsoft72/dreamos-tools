# Steam

Valve's game store and launcher: buy, download and play thousands of games, with Proton for Windows titles.

## Notes

- Installed with `apt`, so dependencies are resolved automatically.
- On Ubuntu and derivatives the `multiverse` repository is enabled first and the package is `steam`.
- On Debian the `contrib` and `non-free` components are enabled and the package is `steam-installer`.
- The 32-bit (`i386`) architecture is enabled, as Steam needs it.
- Steam updates itself on first launch (it downloads its client files).
- Re-run **Install** to update the package.

More information on [the project site](https://store.steampowered.com/about/).
